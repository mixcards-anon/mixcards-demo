MixCards: Evaluating Structured Descriptions of Multi-Source Sound Scenes

Anonymous Authors
Anonymous submission · under review
PaperEvaluation codeDataset

Abstract

Audio language models typically describe a polyphonic audio clip with a single sentence. This format does not explicitly communicate which properties belong to each source and can hide errors in source descriptions. Measuring these errors is difficult because existing datasets do not provide separate, structured descriptions for each source in a polyphonic scene. We introduce MixCardsBench, a benchmark for structured captioning of polyphonic audio that evaluates how well models can generate structured descriptions for each source in mixtures of speech, music, and sound effects, using a fixed metadata schema (e.g., sounding object, sounding action, perceived audio quality, and temporal descriptors). The benchmark contains 4933 ecologically plausible synthetic soundscapes with up to eight overlapping sources built from high-quality recordings and source-level annotations, where each source has a reference description. We evaluate six state-of-the-art large audio language models and find that they often omit or merge sources and assign incorrect properties to detected sources. MixCardsBench exposes errors that clip-level captioning metrics do not measure and supports the development of models that generate structured descriptions of audio scenes.
