Sound effects

Sound-effect stems come from a professional sound-effects library. The file names, descriptions and categories shown on the cards are the library's own metadata for the source recordings.

Speech

Speech stems are synthetic: each utterance was re-synthesised with a voice-cloning text-to-speech system using reference voices from public read-speech corpora, so no original recording of a real speaker is included.
